# 헤더 로고 및 엑셀 버튼 배치 설계

## 목표

모바일 관리자 화면의 `JY:ON` 로고를 현재보다 선명하게 보이도록 확대하고, 엑셀 다운로드 버튼을 로고 바로 오른쪽에 유지한다. 헤더 아래의 부서 칩과 본문 위치, 화면 전환과 로그아웃 동작은 바꾸지 않는다.

## 확인된 기준

- 기준 캡처: `C:\Users\USER\AppData\Local\Temp\codex-clipboard-1tX9Bv.png`
- 기준 뷰포트: `401 × 725px`
- 첨부 파일에는 별도 주황·빨강 박스 픽셀이 포함되지 않았다.
- 사용자가 엑셀 버튼 위치를 `로고 오른쪽`으로 확정했다.
- 엑셀 다운로드는 현재와 동일하게 `master` 역할에만 노출한다.

## 검토한 방식

1. 권장안: 401px 화면에서 로고를 96px로 확대하고 엑셀 버튼을 8px 간격으로 이어 배치한다. 화면 전환 컨트롤과 약 12px 간격을 확보할 수 있다.
2. 112px 이상 확대: 로고 가독성은 높지만 엑셀 버튼과 우측 화면 전환 컨트롤이 가까워지거나 겹칠 수 있어 제외한다.
3. 현재 80px 유지: 기존 버튼 위치는 보존되지만 사용자가 요청한 로고 확대 효과가 부족해 제외한다.

## 최종 배치

- `401px` 기준 로고: `x=14`, `y≈20`, `96 × 약 25px`.
- 엑셀 버튼: 로고 오른쪽 8px 간격, `40 × 40px`.
- `400px` 이하에서는 기존 80px 로고 크기를 유지해 좁은 화면 충돌을 방지한다.
- 넓은 화면에서는 최대 112px까지만 확대한다.
- 브랜드 행 높이 79px, 부서 칩과 본문 시작 위치는 유지한다.
- 원본 PNG의 비율과 투명 배경을 유지하고 `next/image` 최적화를 계속 사용한다.

## 변경 범위

- `app/(protected)/layout.tsx`: 반응형 `sizes` 값만 조정.
- `app/design-v3.css`: 로고 기본 크기와 400px 이하 축소 규칙 조정.
- `scripts/verify-design-v3-skin.cjs`: 크기·배치 계약 검증 갱신.
- `design-qa.md`: 같은 화면 상태의 전후 비교 결과 갱신.

## 변경하지 않는 범위

- 엑셀 다운로드 URL과 파일 생성 로직
- 역할과 권한 판정
- 화면 전환, 로그아웃, 부서 선택
- 출결·GPS·MDM·Supabase·Google Sheet 기능

## 검증 기준

- 401px 마스터 화면에서 로고와 엑셀 버튼이 로고 행 안에 나란히 표시된다.
- 두 요소가 우측 화면 전환 컨트롤과 겹치지 않는다.
- 390px 이하에서 기존 안전 크기 80px로 축소된다.
- 일반 관리자 화면에서는 기존 권한 규칙에 따라 엑셀 버튼이 나타나지 않는다.
- 부서 칩과 첫 본문 요소의 세로 위치가 변하지 않는다.
- 타입 검사, 린트, 스킨 계약과 Chrome 시각 검수를 통과한다.
